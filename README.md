# 🌐 LinguaFlow

### Language Translation Tool

LinguaFlow is a simple and user-friendly language translation web application built with Streamlit. It allows users to enter text, automatically detect the source language, select a destination language, and receive a translated result through a local LibreTranslate REST API.

The application is designed as a practical translation workspace with additional features such as translation history, copy-to-clipboard, text-to-speech, and clear controls.

---

## ✨ Features

- 🌍 Automatic language detection
- 🔄 Translation between supported languages
- 📝 Simple and clean translation workspace
- 📋 Copy translated text
- 🔊 Listen to translated text using text-to-speech
- 🗑️ Clear translation input
- 🕘 Translation history
- 🔁 Source and destination language selection
- ⚠️ Input validation and error handling
- 🧠 Improved handling of short informal inputs
- 📱 Responsive Streamlit interface
